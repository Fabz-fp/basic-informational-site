# Basic Informational Site

A simple informational website built with Node.js as part of The Odin Project.

## Features
- Home page served at /
- About page served at /about
- Contact page served at /contact-me
- Custom 404 page for unknown routes
- Reusable sendFile() helper function for serving HTML files
- Appropriate HTTP status codes for successful requests and missing pages

## Technologies Used
- Node.js
- JavaScript
- HTML5

# What I Learned
Creating an HTTP server with Node.js
Handling URL-based routing
Reading files asynchronously with Node.js
Returning HTTP status codes
Refactoring duplicated code into a reusable function
